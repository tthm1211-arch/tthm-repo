当前版本暂未启用退件揽收的每日调度机制。系统通过绑定【司机】与【驿站组】确定司机的固定揽收范围，司机每天前往所绑定驿站组下的驿站执行退件揽收任务。

后续版本将新增【退件揽收任务管理】功能，引入每日任务快照机制。系统根据预设的【司机－驿站组】绑定关系生成当日任务快照，并支持根据实际运营情况进行临时调整。

退件揽收调度涉及以下管理端模块：
```
管理端
├─ 调度管理
│   └─ 退件揽收任务管理
└─ 订单管理
    └─ 退件揽收单
```

| 模块       | 路径              | 功能                                   |
| -------- | --------------- | ------------------------------------ |
| 退件揽收单    | 调度管理 → 退件揽收任务管理 | 查看和跟踪系统中已生成的退件揽收单及其当前状态              |
| 退件揽收任务管理 | 调度管理 → 退件揽收单    | 管理当日退件揽收任务，查看司机与驿站的任务分配，并处理临时转单等调度调整 |
