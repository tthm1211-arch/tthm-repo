【退件揽收单】用于查询和管理系统中已生成的退件订单，可查看退件当前状态、收件驿站、揽收司机、退件仓及各环节操作时间等信息。

同时支持查看退件面单、导入/导出退件单，以及在退件完成仓库收件后执行【退回客户仓库】，完成退件流程闭环。

### 退件状态与轨迹节点说明

退件订单正常情况下按照以下流程流转：
**已生成 → 驿站收件 → 司机收件 → 仓库收件 → 退回客户仓库**

| 状态     | 轨迹节点                          | 触发                       |
| ------ | ----------------------------- | ------------------------ |
| 已生成    | Label Created                 | 创建订单                     |
| 驿站收件   | Shipment received by NB Store | App驿站端扫描收件               |
| 司机收件   | Driver receive                | App派送端司机扫码揽收             |
| 仓库收件   | Arrive warehouse              | 退件返仓后仓库扫描收件              |
| 退回客户仓库 | Delivered                     | 手动在退件揽收单页面点击【退回客户仓库】闭环订单 |

### 司机与退件对应关系说明
司机与退件以实际揽收操作对应：
- **司机有扫描揽收**：显示实际执行扫码操作账号对应的司机；
- **司机未扫描揽收**：显示该收件驿站所属驿站组绑定的司机。

因此，在查询实际揽收司机时，需要注意司机是否执行过扫描揽收。

### 退件单查询
进入【退件揽收单】页面后，可根据以下条件查询订单：
- **单号**：创建退件订单时生成的退件单号
- **状态**：查询处于指定退件状态的订单
- **委托客户**：目前主要包括 SHEIN、TEMU 和 YSP
- **来源城市**：退件订单的发出城市
- **生成日期**：退件订单创建日期
- **收件驿站**：用户投递退件的驿站
- **入站时间**：驿站扫描收件时间
- **司机**：退件对应的揽收司机
- **司机取件时间**：司机扫描揽收时间
- **退件仓**：退件对应的收件仓库
- **入仓时间**：仓库扫描收件时间
- **返回客户时间**：订单进入【退回客户仓库】状态的时间
- **收件人 / 收件手机号**：一般为委托客户及对应联系电话

### 退件揽收页操作
#### 查看退件面单
退件面单可通过【面单路径】查看，有以下两种方式：
1. 从列表查看
	在【退件揽收单】列表中找到【面单路径】，点击【查看】，系统会在新标签页中打开对应的退件面单。
2. 从订单详情查看
	在订单操作列点击【详情】，进入退件揽收单详情侧边页，在【基础信息】中找到【面单路径】，打开对应 URL 即可查看面单。

#### 退回客户仓库
只有状态为【仓库收件】的退件单才可以执行【退回客户仓库】
<ZoomImage src="/Pasted image 20260827145658.png" alt="退回客户仓库" />

操作方法：
1. 在【退件揽收单】页面将【状态】筛选为【仓库收件】
2. 如有需要，可继续通过【委托客户】、【入仓时间】等条件缩小查询范围
3. 勾选需要退回客户仓库的退件单
4. 点击列表上方的【退回客户仓库】
5. 在弹窗中上传退件回执
6. 点击【确定】完成操作

完成后，订单状态更新为【退回客户仓库】，退件流程闭环。

### 常见问题：
1. 为什么部分订单没有退件仓？

	只有订单进入【仓库收件】状态后，才会产生对应的推荐仓数据。因此，订单尚未完成仓库收件时，【退件仓】字段可能没有对应数据。
2. 为什么点击【退回客户仓库】会报错？

	如果所选退件单中存在状态不是【仓库收件】的订单，系统会提示：“选择的数据中包含非仓库收件”，需要重新筛选订单，确保所选退件单全部处于【仓库收件】状态后再进行操作。
