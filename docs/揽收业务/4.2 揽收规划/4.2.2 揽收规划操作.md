揽收规划用于对预约揽收任务进行统一调度。调度人员可查询指定日期及口岸仓库下的预约揽收任务，根据任务所在区域批量选择待分配订单并分配司机；对于已经完成司机分配的任务，也可根据实际情况重新转派给其他司机。

整个揽收规划流程主要分为：

> **查询揽收任务 → 选择待分配任务 → 分配司机 → 查看已分配任务 →
> 必要时转单**

功能路径：调度管理 → 路径规划 → 揽收规划
### 查询揽收任务
进入揽收规划页面后，可根据**口岸仓库、取件时间及预约单号**查询需要处理的预约揽收任务。

- 取件时间：最早取件时间和最晚取件时间默认均为**当天日期**。如需查询其他日期的预约揽收任务，需要先调整取件时间范围。
- 口岸仓库：【待分配】和【已分配】状态下的口岸仓库查询规则不同 -- 待分配列表必须选择口岸仓库，否则列表不显示查询结果；已分配列表口岸仓库可以为空，为空时默认查询 **Toronto Warehouse**已分配揽收单
- 预约单号：通过预约单号查询时，当前选择的**口岸仓库、取件时间及任务状态**均需与该预约揽收单的实际信息匹配。
	>例如，某预约揽收单的取件日期不是当天，在默认取件日期下仅输入预约单号进行搜索，系统不会返回该订单。需要先将取件时间调整至对应日期，再进行查询
- 重置：点击重置后，取件日期恢复为默认日期，已选择的口岸仓库不会被清空。

### 选择待分配任务
【待分配】用于处理尚未分配司机的预约揽收任务。

待分配列表按照**路线号**进行分组，每个路线号下集中展示属于该路线的预约揽收单。

#### 1. 选择任务
可直接在任务列表中选择订单，也可通过地图批量框选同一区域的任务。

使用地图框选时：

1.  进入 **【待分配】**。
2.  按住 **Shift** 键。
3.  在地图中框选需要规划的区域。
4.  系统自动选择框选区域内符合条件的待分配任务。
5.  被选中的任务进入**已锁定**状态。

#### 2. 确认已选任务

任务被选中后，页面进入锁定模式，并自动切换至 **【已锁定】**。【已锁定】中集中展示本次准备分配司机的所有预约揽收任务。

地图图钉与任务列表中的**排序编号**保持对应，便于确认地图位置与具体订单。如果某个订单不需要参与本次分配，可取消任务卡片左侧的勾选。取消后：

> 列表取消选中 → 对应地图图钉同步取消选中

锁定期间，【待分配】和【已分配】暂时无法正常查看。

#### 3. 分配司机

确认任务无误后，点击 **【分配司机】**，选择负责本次揽收任务的司机。

页面存在两个【分配司机】入口：

-   顶部已选任务状态栏；
-   【已锁定】列表底部。

两个入口功能相同。

完成司机确认后：

> **已锁定 → 分配司机 → 退出锁定模式 → 返回待分配**

对应任务完成司机分配，并进入【已分配】。

#### 4. 取消本次规划

如果不需要继续当前规划，可点击 **【清空】**。

系统将：

-   取消当前任务选择；
-   解除已选任务的锁定状态；
-   退出锁定模式；
-   返回【待分配】。

### 已分配任务
【已分配】用于查看已经完成司机分配的预约揽收任务。

与【待分配】按照路线号展示不同，【已分配】按照**司机**进行分组，每名司机下集中展示当前分配给该司机的预约揽收任务。通过该页面可以确认不同司机当前负责的揽收任务，也可以对已经分配的任务进行转单。
#### 转单
如果预约揽收任务已经分配司机，但后续需要更换执行司机，可通过【转单】重新分配。

操作步骤：

1.  进入 **【已分配】**。
2.  选择对应口岸仓库及取件时间。
3.  查询需要调整的预约揽收任务。
4.  勾选需要转单的订单。
5.  点击 **【转单】**。
6.  在快速转单窗口中选择新的司机。
7.  点击 **【确定】**。

操作完成后，所选预约揽收任务将从原司机转派至新司机。
